# csharp-design-patterns

Four classic GoF design patterns implemented in modern C# (.NET 8), each with
a runnable demonstration:

- **Singleton** — thread-safe lazy `AppConfig`
- **Factory** — `ShapeFactory` producing circles and rectangles
- **Strategy** — swappable sorting algorithms via `ISortStrategy`
- **Observer** — a tiny news feed with subscribers

## Run
```bash
dotnet run
```
